#
# 规则（由 tool/mutate.sh 强制，fail-closed）：
#   * 原文必须是**单行**，并且在目标文件里出现次数恰好为 1（否则硬失败）
#   * 原文里不能出现 `|`：分隔符会把它切碎、字段数变多（这类条目被判硬失败）；
#     替换里同理——虽然解析上能容，但别依赖「最后一个字段吞掉多余分隔符」这点
#   * 替换后必须能通过 `go vet ./...`（编译不过 = 硬失败）
#   * 每个变异体都必须让 `go test ./... -count=1` 失败（存活 = 验证有盲区）
#
